# 05 接口设计

> REST 风格，Knife4j 在线文档。本文只列端点清单与统一约定，字段细节以 [03-数据库设计](03-数据库设计.md) 为准。

## 一、统一约定
- **前缀**：`/api`；管理端 `/api/admin/**`（role=2 拦截）
- **鉴权**：`Authorization: Bearer <JWT>`；白名单：注册/登录/Knife4j
- **返回**：`Result{code, message, data}`，code=0 成功；分页 `data{records, total, page, size}`
- **幂等**：下单、入金、出金必传 `requestId`（客户端 UUID，≤64 字符），服务端按 `(userId, requestId)` 去重：下单重复返回原单，入金/出金重复返回原流水结果
- **时间**：`yyyy-MM-dd HH:mm:ss.SSS`；金额字符串传输避免精度丢失
- **校验**：Jakarta Validation 参数校验 + 全局异常处理；业务规则校验在 order 模块

## 二、错误码（节选）
| 段 | 含义 | 示例 |
|----|------|------|
| 0 | 成功 | - |
| 1xxx | 通用 | 1001 参数错误 / 1002 未登录 / 1003 无权限 / 1004 请求过频 |
| 2xxx | 账户 | 2001 余额不足 / 2002 账户冻结 / 2003 可卖持仓不足 / 2004 重复提交 |
| 3xxx | 订单 | 3001 涨跌停限制 / 3002 非整手 / 3003 T+1 限制 / 3004 停牌 / 3005 非交易时段 / 3006 重复提交 / 3007 状态不允许撤单 |
| 4xxx | 撮合 | 4001 无对手盘 / 4002 撮合冲突重试 |
| 5xxx | 系统 | 5001 系统繁忙 / 5002 下游超时 |

## 三、端点清单

### 鉴权与用户
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /api/auth/register | 注册（自动开户） | 公开 |
| POST | /api/auth/login | 登录签发 JWT | 公开 |
| GET | /api/user/profile | 个人信息 | 用户 |
| PUT | /api/user/profile | 修改个人信息 | 用户 |

### 资金账户
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /api/account | 账户余额/冻结/可用/总资产 | 用户 |
| POST | /api/account/deposit | 模拟入金（含 requestId） | 用户 |
| POST | /api/account/withdraw | 模拟出金（含 requestId） | 用户 |
| GET | /api/account/flows | 资金流水分页 | 用户 |

### 行情
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /api/stocks | 股票列表分页 | 用户 |
| GET | /api/stocks/{code} | 股票基础信息 | 用户 |
| GET | /api/stocks/{code}/quote | 最新行情 | 用户 |
| GET | /api/quotes | 批量行情查询 | 用户 |

### 订单与成交
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST | /api/orders | 创建限价单（买/卖，含 requestId） | 用户 |
| GET | /api/orders | 我的订单分页（状态/时间筛选） | 用户 |
| GET | /api/orders/{orderNo} | 订单详情 | 用户 |
| POST | /api/orders/{orderNo}/cancel | 用户主动撤单（第二轮） | 用户 |
| GET | /api/deals | 我的成交分页 | 用户 |

### 持仓
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | /api/positions | 持仓列表（含实时市值/浮盈） | 用户 |
| GET | /api/positions/flows | 持仓流水分页 | 用户 |
| GET | /api/assets/snapshots | 历史资产快照分页 | 用户 |

### 管理端
| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| POST/PUT | /api/admin/stocks | 股票信息新增/修改 | 管理员 |
| PUT | /api/admin/stocks/{code}/status | 停牌/复牌/退市 | 管理员 |
| POST | /api/admin/quotes/refresh | 手动触发行情刷新 | 管理员 |
| GET | /api/admin/settlement/batches | 清算批次查询 | 管理员 |
| POST | /api/admin/settlement/run | 手动触发日终清算（第一轮=最小日切：过期撤单+行情日切+T+1清零） | 管理员 |
| GET | /api/admin/reconcile/diffs | 对账异常列表 | 管理员 |
| PUT | /api/admin/reconcile/diffs/{id} | 差错处理（标记/冲正） | 管理员 |

## 四、安全要点
密码 BCrypt 存储；JWT 设过期时间、密钥外置配置；管理端 role 拦截 + 操作审计（sys_operation_log）；MyBatis-Plus 参数化防注入；手机号等敏感字段返回脱敏；下单/行情接口限流（第二轮 Redis 令牌桶，预留）。
